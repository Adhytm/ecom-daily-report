# 电商销售日报与经营诊断技能包

本技能为电商日常运营与管理提供“表格解析 → 自动识别平台 → 归一化聚合 → 异常指标检测 → 生成 Excel 日报与群发摘要 → 深度经营归因”的全自动化能力。

---

## 1. 适用场景与触发时机

当用户提出以下需求时唤醒本技能：
1. **生成日报/周报**：“帮我跑一下今天的销售日报”、“处理一下导出的电商报表”、“出一下这周的销售周报”。
2. **群发摘要提取**：“把今天报表的群发摘要发我”、“提取一下今天的微信/钉钉战报”。
3. **经营异动与异常归因**：“今天利润怎么跌了？”、“分析一下今天退款率飙升的原因”、“今天哪几个爆款 SKU 出了问题？”。
4. **报表数据查询**：“查一下 2026-09-06 各平台的 GMV 和 ROI 分布”。

---

## 2. 核心操作规程

### 任务 A：一键生成销售日报与群发摘要

当用户要求跑报表或提供了新的平台导出文件时：

1. **定位输入文件**：
   - 默认输入目录为 `portable/输入表格放这里/`。
   - 若用户指定了特定目录或文件，使用 `--input-dir <path>`。
2. **执行生成命令**：
   ```powershell
   python skill/scripts/run_report.py --json
   ```
   *（若在当前项目虚拟环境下，使用 `.venv\Scripts\python skill/scripts/run_report.py --json`）*
3. **交付成果**：
   - 在回复中直接提供格式优美的【群发文字摘要】（≤800字，微信/钉钉友好）。
   - 给出生成的 7-Sheet Excel 文件绝对路径。
   - 列出今日需要立即关注的红黄预警项。

---

### 任务 B：多维度数据查询与异常归因诊断

当用户询问店铺为何下滑、退款为何激增、或需要大盘深挖时：

1. **执行指标与异常查询**：
   ```powershell
   python skill/scripts/query_metrics.py --date <YYYY-MM-DD> --section all
   ```
2. **经营归因三段式分析**：
   结合返回的 JSON 数据以及 `skill/references/metrics.md` 中的口径定义，向用户输出结构化的诊断建议：
   - **【大盘异动归因】**：GMV / 实际成交额的核心拖累或拉动因素（是客单价跌了、还是进店流量少了、还是转化率崩了）。
   - **【平台与爆款风险】**：识别触发了红黄警报的平台与 SKU（如退款率 $\ge +5pp$、ROI 跌破 1.0、客单价跳水）。
   - **【明日 Action Plan】**：针对上述问题给出具体运营动作（例如“暂停 ROI 倒挂计划”、“排查某 SKU 差评退款原因”、“补齐未映射 SKU 成本价”）。

---

## 3. 指标口径与计算红线

- **比率类指标必须使用百分点（pp）**：退款率、转化率、费比等变动严禁使用乘除百分比，必须用 `+X.X pp` 或 `-X.X pp`。
- **毛利严禁虚报**：未录入 SKU 成本价的商品，毛利严格为 `None`，绝不用假定比例糊弄用户。
- **京东 GMV 特殊口径**：京东商智成交额通常含运费，涉及京东 GMV 时需保留运费口径提示。
