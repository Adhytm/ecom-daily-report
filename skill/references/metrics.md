# 电商核心指标口径与预警规则指南

本参考文档供 AI Agent 查阅，用于做经营归因、异常诊断和回答用户业务问题。

---

## 1. 核心衍生指标计算公式

- **客单价 (AOV / Avg Order Value)**：
  $$客单价 = \frac{实际成交额 (net\_amount)}{买家数 (buyers)}$$
- **件单价 (Unit Price)**：
  $$件单价 = \frac{实际成交额 (net\_amount)}{支付件数 (paid\_qty)}$$
- **退款率 (Refund Rate)**：
  $$退款率 = \frac{退款金额 (refund\_amount)}{GMV}$$
- **支付转化率 (Conversion Rate)**：
  $$转化率 = \frac{买家数 (buyers)}{访客数 (visitors)}$$
- **推广投入产出比 (ROI)**：
  $$ROI = \frac{实际成交额 (net\_amount)}{推广花费 (ad\_cost)}$$
- **推广费比 (Ad Cost Ratio)**：
  $$推广费比 = \frac{推广花费 (ad\_cost)}{实际成交额 (net\_amount)}$$

---

## 2. 利润核算规则

- **毛利 (Gross Profit)**：
  $$毛利 = 实际成交额 - 货品成本(SKU成本价 \times 件数) - 平台扣点 - 单件履约成本$$
- **经营利润 (Operating Profit)**：
  $$经营利润 = 毛利 - 推广花费 (ad\_cost)$$
- **红线约束**：
  成本未知则毛利为空（`None`），**绝不使用兜底比例虚报**。若成本覆盖率不足 100%，会在报告中明确警示。

---

## 3. 环比与同比表达规范

- **数值类指标**（如 GMV、成交额、件数）：
  使用百分比变动（环比 DoD，周同比 WoW）：
  $$DoD = \frac{今日 - 昨日}{昨日}$$
- **比率类指标**（如 退款率、转化率、推广费比）：
  使用**百分点差值（Percentage Points, pp）**，不得使用百分比乘除：
  $$DoD\_pp = 今日比率(\%) - 昨日比率(\%)$$

---

## 4. 默认 6 大异常预警规则

| 规则名称 | 适用指标 | 判定条件 | 级别 | 业务含义 |
| :--- | :--- | :--- | :--- | :--- |
| **GMV 大幅异动** | `gmv.dod` | 绝对值 $\ge 30\%$ | 🔴 严重 | 大盘或单店规模剧烈波动 |
| **退款率飙升** | `refund_rate.dod_pp` | 增长 $\ge +5.0pp$ | 🔴 严重 | 货品质量问题、批量退单或刷单 |
| **推广 ROI 倒挂** | `roi` | $< 1.0$ | ⚠️ 警告 | 投流亏损，入不敷出 |
| **转化率大幅下滑** | `conversion_rate.dod_pp` | 下滑 $\le -2.0pp$ | ⚠️ 警告 | 流量不精准、主图/详情页/价格变动 |
| **客单价剧烈跳水** | `avg_order_value.dod` | 下跌 $\le -20\%$ | ⚠️ 警告 | 满减凑单失控、低价货冲量 |
| **推广费激增** | `ad_cost.dod` | 激增 $\ge +50\%$ 且 ROI 下滑 | ⚠️ 警告 | 投流预算超标 |
